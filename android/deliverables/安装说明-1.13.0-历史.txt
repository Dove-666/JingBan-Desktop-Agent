AURA 安卓伴侣 1.13.0（versionCode 16）

近年安卓手机安装 AURA-1.13.0-arm64-v8a.apk；不确定处理器时选 universal。
最低 Android 8.0，同一手机只需安装一份。沿用原签名，可直接覆盖旧版，保留配置和聊天记录，无需卸载或清除数据。

本版改进：
• 显示新版电脑工具的三项安全进度：分工阅读资料、查看文档页面、计算项目产物。
• 项目计算环境无效或配置变化时显示固定中文提示，不同步内部错误或模型隐藏推理。
• 保留鲸鱼娘图标、玻璃界面、当前对话主题、手机直接 API 图文聊天、电脑任务队列与记录同步。

手机独立聊天：欢迎页选择“配置模型，直接聊天”，填写手机可访问的 HTTPS 接口、模型和 API Key。
连接电脑：电脑打开“远程连接”，复制完整 aura://pair/ 长链接或 JSON，在手机“连接我的电脑”中粘贴并确认，不要只填短配对码。
电脑源码更新后先保存草稿，再从系统托盘完整退出桌宠并重新启动；仅关闭聊天窗口不会加载新版代码。
电脑工具是否可用由电脑权限和实际环境决定；更新手机 App 不会自动启用工具或扩大权限。

已检查：183 项 Android 单元测试、Release Lint（0 错误）、3 项模拟器仪表化检查，四份 APK 原签名/ABI/16 KiB 对齐，1.12→1.13 不清数据覆盖升级，以及正式包三项新标签展开显示。
升级哨兵使用明确合成的会话及假配对字段，不代表真实手机配对或 Android Keystore 连续性；本轮没有调用模型或连接电脑。手机实机、移动网络及公共中继未在本版实测。
详细证据见 artifacts/companion-1.13.0/verification.json，详细说明见 android/README.md。
旧版安装说明保存在“安装说明-1.12.0-历史.txt”。
