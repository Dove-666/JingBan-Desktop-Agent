AURA 安卓伴侣 1.14.0（versionCode 17）

近年安卓手机安装 AURA-1.14.0-arm64-v8a.apk；不确定处理器时选 universal。
最低 Android 8.0，同一手机只需安装一份。沿用原签名，可直接覆盖旧版，无需卸载或清除数据。

本版改进：
• 切换对话、旋转屏幕时保留未发送草稿。
• 粘贴长文本不再静默截断；超过 8000 字时保留全文，提示编辑后再发送。
• 明确比较新图与上一张图片时携带两图；普通新话题不再误带旧照片。
• 比较所需旧图缺失时先提示，保留当前文字和图片，不发起缺少材料的模型请求。
• 保留鲸鱼娘图标、玻璃界面、对话主题、手机直接 API 图文聊天、电脑任务队列与记录同步。

手机独立聊天：欢迎页选择“配置模型，直接聊天”，填写可访问的 HTTPS 接口、模型和 API Key。
连接电脑：电脑打开“远程连接”，复制完整 aura://pair/ 长链接或 JSON，在手机粘贴并确认，不能只填短配对码。
电脑源码更新后先保存草稿，再从系统托盘完整退出桌宠并重新启动；仅关闭聊天窗口不会加载新版代码。

已检查：201 项 Android 单元测试、Release Lint、四份 APK 原签名/ABI/16 KiB 对齐，1.13→1.14 不清数据覆盖升级。
草稿与长文本修复另经 11 项 Debug 模拟器界面检查；正式包界面验收独立记录。
本轮没有使用实体手机、真实配对、移动网络或公共中继，不能把模拟器升级等同这些环境通过。
