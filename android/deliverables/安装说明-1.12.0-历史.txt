AURA 安卓伴侣 1.12.0（versionCode 15）

近年安卓手机安装 AURA-1.12.0-arm64-v8a.apk；不确定处理器时选 universal。
最低 Android 8.0，同一手机只需安装一份。沿用原签名，直接覆盖安装，保留配置和聊天记录，无需卸载或清除数据。

本版改进：
• 支持新版电脑的任务排队；另一对话可在电脑忙碌时提交，电脑确认接收后顺序执行。
• 收到重复回执仍对应原任务；结果未知时查询原操作，避免重复执行。
• 保留手机直接 API 聊天、图文识别、离线电脑时的手机聊天、配置与记录同步、执行过程和文件交付卡片。
• 保留鲸鱼娘图标、玻璃界面、当前对话主题标题和简洁输入区。

手机独立聊天：欢迎页选择“配置模型，直接聊天”，填写可由手机访问的 HTTPS 接口、模型和 API Key。
连接电脑：电脑打开“远程连接”，复制完整的 aura://pair/ 长链接或 JSON，在手机“连接我的电脑”中粘贴并确认。不要只填短配对码。
新版电脑功能需要更新源码后从系统托盘退出旧进程，再重新启动。先保存尚未发送的草稿；只关闭聊天窗口不会重启电脑端。
“电脑 Agent”使用电脑已启用的工具和权限，升级不会自动扩大授权。执行中当前对话的补充指令继续交给同一个任务。
未连接时不创建以后自动操作电脑的任务。普通手机聊天只需要手机能访问模型接口；电脑可关机，重连后再同步记录。

已检查：181 项单元测试、Release Lint、四份 APK 的原签名/ABI/16 KiB 对齐；专用模拟器覆盖升级保留数据库与配置；实际正式包逐段回复、停止、下一条回复和主题标题。
手机实机、移动网络与公共中继尚未在本版实测，模型能力基准与安装包检查分开记录。
详细说明见 android/README.md；旧版本说明保存在“安装说明-1.10.0-历史.txt”。
