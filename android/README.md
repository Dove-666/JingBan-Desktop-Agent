# AURA 安卓伴侣

手机端连接家中运行的 AURA 桌宠，支持同步对话、发送消息、传送图片和控制桌宠。手机沿用电脑配置的 AI，无需在手机填写模型密钥。

## 安装与配对

1. 安装 `deliverables` 中的 APK。普通近年安卓手机优先选 `arm64-v8a`；不确定处理器时选 `universal`。最低 Android 8.0。
2. 电脑安装远程组件：在项目根目录运行 `.venv\Scripts\python.exe -m pip install -r requirements-remote.txt`，然后启动桌宠。
3. 在电脑的「控制台 → 远程连接」或托盘「手机远程连接」中开启功能，生成并复制配对信息。
4. 在手机点击「连接我的电脑」，粘贴完整配对信息并确认。配对码五分钟内有效，只能使用一次；之后由设备密钥自动认证。

电脑需要保持运行、联网且未休眠。手机可以用移动网络，电脑可以用家中 Wi-Fi。连接优先尝试直连，无法直连时使用 iroh 提供的公共中继；不需要自行租服务器。公共网络和中继的可达性会影响连接成功率及延迟。

## 对话与同步

- 首次连接下载电脑的会话和消息，之后同步变化。历史保存在手机 SQLite 数据库，离线仍可阅读。
- 手机前台运行时定期同步；切到后台后关闭通信以节省电量，重新打开会自动连接。不申请后台常驻权限，也不提供后台推送通知。
- 离线消息和图片保存在待发队列，重连后继续发送。丢失响应时先查询原操作状态，避免重复触发电脑的 AI 回复。
- 电脑删除的会话会同步删除。属于已删除会话或另一台电脑的待发内容保留供手动处理，不会悄悄投递到新会话。
- 电脑负责实际 AI 推理。手机中的聊天和电脑已有会话使用同一份记录，手机不另外调用模型。
- 每次在内存中显示当前会话最近 500 条消息；完整同步记录保存在手机数据库。

## 图片与桌宠

系统选图器无需相册存储权限。手机会先缩小相机原图，再上传到电脑的图片收件箱；单张传输上限 4 MiB，静态 PNG/JPEG/WebP。图片缓存上限 64 MiB。图片上传目前是文件传送，不会自动交给模型识图。

桌宠控制包括表情、缩放、显示/隐藏和说一句话。动作只在连接时发送，离线不会排队重放。

## 本地构建

需要 JDK 17 或更新兼容版本、Android SDK 平台 35 和 Build Tools 35。项目使用 Gradle Wrapper，不需要安装 Android Studio。当前工作机的 SDK 位于 `E:\Android\Sdk`，JDK 位于 `E:\Biancheng`。

```powershell
cd E:\github\AURA-Desktop-Agent\android
.\build-apk.ps1
```

构建脚本先运行单元测试及 Release Lint，再生成签名安装包。可用 `-SdkPath`、`-JdkPath` 和 `-SigningDirectory` 指定路径；`-SkipTests` 只适合已验证相同源码后的打包。

发布签名保存在项目外 `E:\Android\keys\aura-companion-release.p12`，密码使用当前 Windows 用户的 DPAPI 加密保存在同目录。后续更新 APK 必须保留同一签名。密钥和受保护凭据不要提交到仓库；DPAPI 凭据不能直接在另一 Windows 账号解密，迁移前应单独安全导出签名凭据。

设备身份由 Android Keystore 保护；不保存一次性配对码。手机应用关闭 Android 云备份和设备迁移备份。电脑可随时撤销手机授权，撤销后手机需要手动重新配对。

UI 使用原生 Jetpack Compose、系统字体和自绘图标，提供浅色、深色及跟随系统主题。测试用示例记录只位于 instrumentation 测试 APK，不会进入发布安装包。

## 已验证范围

- 27 项 JVM/Robolectric 单元测试通过，Release Lint 无错误。
- Android 15 / API 35 模拟器上，11 项独立 UI 测试通过；检查了浅深色、1.3 倍字体、离线记录、配对、队列、图片及 Markdown。
- 真实 Android JNI/QUIC 到隔离电脑程序的配对、快照同步、增量同步、离线重连、图片上传下载、桌宠动作、删除传播与撤销授权通过。AI 模型使用本地模拟接口，未消耗用户模型额度。
- 最终经过 R8 优化的签名发布 APK 已实际安装，并通过正式界面的配对、发送及同步回复验证。四份 APK 的签名、ABI、16 KiB 原生库及 ZIP 对齐均通过检查。
- 发布版在 x86_64 模拟器联网后的总 PSS 约 55 MiB；手机实机占用会随系统、聊天内容和图片变化。

目前没有用户手机、移动网络及 Android 8.0 实机测试结果。模拟器测试观察到直连路径，公共中继和跨运营商网络可达性仍需实机验证。详细记录位于项目的 `artifacts/android/qa/`；界面截图使用隔离测试内容。
