问问鲸鱼娘

在网页中选中文字，右键选择“问问鲸鱼娘”，即可带着这段文字和页面正文打开桌宠对话。

  1. 先启动 AURA 鲸鱼娘桌宠。
  2. 首次使用，在项目目录运行 powershell -NoProfile -ExecutionPolicy Bypass -File tools/install_browser_ask.ps1 -Apply。
  3. 在 Edge 或 Chrome 扩展页开启开发人员模式，加载项目的 browser-extension/whale-ask 文件夹。
  4. 返回网页，选中文字并右键重试。

仅在点击菜单时读取文字，不截图，不读取密码框，也不会向浏览器提供 API Key。浏览器内置页与部分受限页面无法读取正文。
