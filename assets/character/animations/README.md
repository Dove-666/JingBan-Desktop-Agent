# 动作成品目录：已发布

新增 `idle_tsundere/`（待机 · 傲娇抱臂）：复用 `../static/tsundere.png`，30 张 1024 RGBA 帧、12 FPS；短暂淡入、原姿态停留 2 秒、淡回 neutral。它是明确的静态姿态待机，继续叠加程序原有呼吸效果，没有重新生成视频。自动待机时与其余 7 个动作一起随机轮换；手动预览可循环，静态角色下拉框仍可固定显示傲娇角色。

本目录已发布两段真实 SAM2 视频分割成品。每段均为 62 张 1024×1024 RGBA 帧、12 FPS、5167ms，`complete:true`、`qa_passed:true`；两段实际源视频均为 24 FPS、124 帧且已全部分割。预算 2/2、实际合计3元，不再提交或重试。来源和生成偏差见[生产清单](../production_manifest.json)。

每帧都是完整的 1024×1024 RGBA 画布，共享底部锚点 `(512,960)`；不得逐帧裁切并重新居中。交付帧数、FPS 与时长必须反映真实序列，缺少尾帧或未通过视觉验收时保留草稿，不能只把 `complete` 改成 `true`。

播放时按各帧实际边界预先规划贴边避让，位移在动作内部完成，末帧回到播放前的位置。同一侧的避让只连续离开、保持、归位，不因道具轮廓短暂收缩而反复左右调整；边界冲突时优先保证画面完整。首尾与当前静态图片完全相同时直接衔接，不重复插入淡化或在恢复静态后滑行；贴边动作被手动中止时先淡出，在透明帧归位后淡入。拖动会更新落点，缩放和屏幕工作区变化会重新计算位置，不会恢复过时坐标。

避让在满足画面边界和速度限制时使用平滑的缓入缓出曲线。拖动或缩放后重新开始当前帧的显示间隔，避免把整帧位移挤进剩余的几毫秒；手动循环进入下一轮时清除上一轮的临时落点锚点，沿用新位置重新规划整段动作。

`static_pose_idle` 类型的 12 FPS 静态姿态在后台加载时增加过渡采样，以 24 FPS 播放缓存；相同姿态复用原图，姿态停留时间和总时长保持不变。原始 PNG、视频动作的帧率和静态角色选项均不改动。

「思考 · 挠头」单次播放后回到静态待机（`completion:idle`）；「趴下 · 奶凶呲牙」单次播放后保持末帧（`hold_last`），用「停止 / 恢复」回静态并释放帧缓存。两段都不循环。
