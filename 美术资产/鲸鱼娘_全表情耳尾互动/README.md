# 鲸鱼娘 · 全表情耳尾点击互动

正常、开心、惊讶、困倦、生气、思考、说话七种表情均支持点击左耳、右耳和尾巴轻摆回弹。桌宠中直接点击露出的蓝色鳍耳或右侧尾巴即可；右键菜单的“耳尾点击互动”可开关，切换表情后保持当前选择。

沿用已确认的正常立绘效果：耳朵约 0.65 秒、尾巴约 0.9 秒。只摆动点击部位，头发和蝴蝶结保持遮挡。按住拖动优先，松手后继续回弹。原有眼睛跟随保留，开心表情保持闭眼。说话使用现有张嘴表情，闭嘴备用图与正常图共用分层。

本包集中保存完整七套工程：

- `PSD/`：七份原生 Photoshop 分层工程。正常表情由已验收试版直接复制；另外六份在本机 Photoshop 中分别拆层。
- `透明分层/<表情名>/`：各套的 RGBA 部件、身体底图、修补蒙版、点击蒙版和 `rig.json`。
- `预览/`：逐态深浅背景、休止及正反摆动极值，以及七态联系图。
- `演示/`：桌宠实际绘制的逐表情动画预览。
- `工程/`：Photoshop 脚本、逐态几何、原图指纹、执行日志和美术检查记录。

每张表情都使用自身原图像素，分别核对耳腹、头发边缘和尾巴内侧；没有把正常表情的耳尾直接贴到其他表情上。新资产安装在 `assets/character/interactions/`，原表情、眼睛分层和正常表情的旧互动素材保持原字节。
