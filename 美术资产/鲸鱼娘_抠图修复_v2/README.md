# 鲸鱼娘抠图修复 v2

这里集中保存本轮修复的鲸鱼娘素材。目标是去掉垂发间残留的白块、清理外轮廓白边，并修复已有视频的发孔透明度与偏暗颜色。

常用文件：

| 位置 | 用途 |
| --- | --- |
| `原图_未修改.png` | 用户指定的正常立绘 RGB 原图副本，1254×1254 |
| `鲸鱼娘_透明背景_修复_v2.png` | 完整分辨率正常角色透明 PNG |
| `傲娇_透明背景_修复_v2.png` | 完整分辨率傲娇透明 PNG |
| `桌宠画布/master.png` | 正常角色的 1024×1024 运行画布 |
| `桌宠画布/tsundere.png` | 傲娇角色的 1024×1024 运行画布 |
| `动画/think_scratch_head/` | 挠头疑惑序列帧、动画清单和检查记录 |
| `动画/snarl_cute/` | 奶凶蹲低序列帧、动画清单和检查记录 |
| `源视频/` | 两份原始 MP4，保留未经本轮修改的视频源 |
| `制作记录/` | 蒙版、修复候选及修改前版本；包含被拒绝的试验文件 |

正常角色使用内置图像模型提供的蒙版，配合用户原图颜色进行修复。傲娇保留原有 RGBA 蒙版，只局部清除两个左侧发孔的白背景。两者均保留原角色造型；完整分辨率修复源中，正常角色 772,982 个、傲娇角色 745,772 个不透明像素的 RGB 与各自原图完全一致。运行画布经过等比例缩放，不能拿它的插值像素直接与原图逐像素比较。

本轮没有重新提交视频生成任务。两段原视频的全部 248 个原生帧已通过真实 SAM2 发孔跟踪修正，并采用固定颜色调整；各交付 62 帧、12 FPS、1024×1024 的透明序列，保持共同画布与定位标准。正式视频动画和静态画布已发布到上述目录，并同步到项目运行路径；制作记录中的其他候选文件不代表正式成品。

查看透明 PNG 时建议放到深色或粉色背景上，重点观察左侧垂发两处空隙、右侧发孔、白色头饰和裙边。不要把头饰、围裙或袜子本来就有的白色误认为残留背景。

程序实际加载的是项目 `assets/character/` 中对应的运行素材。发布后完整退出并重启桌宠，再从调试面板的“角色素材与序列帧”切换静态角色、播放两段动作。仅点击“重新检查素材”不能替代默认角色缓存的重新加载。

正常候选3与傲娇候选2已通过独立像素和三种背景审查。本轮 **77 项相关测试通过**，正式路径中的两段真实动画也通过隔离 Qt 播放检查，涵盖六档缩放、拖动冻结与恢复、停止及结束行为。这些自动检查使用 offscreen 窗口，没有使用物理鼠标；原生 Windows 交互须单独核验。

完整方法、来源、保护点、实际命令和验证边界见 [修复说明](../../docs/ASSET_MATTE_REPAIR.md)。
