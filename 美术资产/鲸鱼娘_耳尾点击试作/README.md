# 常驻正常立绘 · 耳尾点击试作

[点击看动图](耳尾点击演示.gif) · [首摆静帧](耳尾首摆效果.png) · [Photoshop 分层工程](PSD/neutral_interaction_rig.psd)

在正常立绘上点击左右蓝色鳍耳或右侧露出的尾巴，对应部位会轻摆、回弹并复位。耳朵约 0.65 秒，尾巴约 0.9 秒。身体维持原有点击功能；从耳尾开始拖动也只会拖动，眼睛继续跟随鼠标。

角色右键菜单中的“耳尾点击互动”可临时关闭试版。其余表情和序列动画保持原有行为，本轮只适配正常常驻立绘。

`PSD/` 是 Photoshop 原生分层文件；`透明分层/` 是源画布底图、三个部件、命中蒙版和 rig 配置；`预览/` 保留深色背景及正负角度细节；`工程/` 包含实际 Photoshop JSX/PowerShell 制作过程、日志和软件窗口证据。运行资产副本安装在项目的 `assets/character/interactions/neutral/`。

原正常 PNG、表情和眼睛素材未改。拆分重建存在少量抗锯齿和隐藏根部差异，因此运行时只重绘正在摆动的部位；未点击部位保留原像素，零角度与结束姿态直接恢复原图。详细美术记录见 [交付说明](交付说明.txt)，交互说明见 [项目文档](../../docs/PART_INTERACTION_TRIAL.md)。

动图是从真实运行渲染帧合成的放大审核预览，便于观察细节。实际桌宠的显示大小仍由当前缩放设置决定。
