# R21 图片存储错误提示

旧选图和新增图片粘贴入口均存在相同问题：有效图片仅因收件箱空间已满或本地读写失败，仍提示选择正确格式、减小至 4 MiB。更换图片无法解决这些存储问题。

受控检查使用 111 字节有效 PNG；只在本进程将配额设为零，或将自有临时目录位置设成普通文件，分别得到真实的配额和文件系统错误。没有填满用户磁盘、分配真实 64 MiB 或修改生产容量。两入口、两类原因的四个原始错误分类断言失败均保留。

现在仅按可信收件箱错误码及本地 `OSError`、SQLite 错误分类：存储已满、读写失败分别显示固定提示，格式问题仍使用原格式提示。后台只传递三个允许的内部错误码，界面继续接收原有 `imageError` 文字字段；不传原始异常、文件路径或密钥。会话和清空代次检查保持在显示结果之前。

新增与既有图片检查合计 30 项通过。另在正式编译网页、真实控制器和图片仓库中完成两项可见验收：420 px 窗口、22 px 字号下，正确原因完整显示，空白及多行草稿逐字保留，随后仍能继续输入。没有创建聊天消息，也没有调用模型。窗口、工作线程和测试夹具均已关闭。
