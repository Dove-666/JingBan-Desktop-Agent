# 桌宠气泡体验调整 · 2026-10-31

旧气泡把整张透明 PNG 画布当作角色，额外预留了弹跳距离，造成实际人物与气泡之间的大块空白；字号下限和固定最小宽度又让小桌宠旁的卡片显得过大。

现在直接使用当前帧的透明轮廓和绘制姿态定位，脸部锚点优先读取眼睛素材的实际坐标。气泡随呼吸、弹跳、拖动和序列帧移动，透明边缘不再决定说话位置。轮廓只在素材布局时测量，帧更新复用缓存。

100% 桌宠的文字为 12pt，宽度至多 300 逻辑像素；50%、75%、125%、150%、200% 对应 6、9、15、18、24pt。卡片宽高预算、文字、内边距、圆角、尾巴和间距一起缩放，工作区不足时再换行和分页。每页保持相同卡片尺寸；阅读中调整大小时保留当前文字位置，避免按旧页码跳过内容。

外观采用近白色背景、深蓝灰文字、浅色细边与轻阴影，减少原先粗蓝边框的存在感。新消息在侧面、斜侧方和上方之间变化；同一消息保持方向，屏幕边缘再换位。正下方只作为空间受限时的兜底：实图检查发现，大号桌宠脚下的气泡虽然离鞋很近，却像字幕，离脸仍远。

普通反馈继续鼠标穿透，关联评论继续点击打开对应会话；两者均不请求键盘焦点。没有新增动画框架、网络请求、字体下载或运行依赖。

## 开源选择

对比了 PyQt Tooltip、PyQtToast、qt-material、QCustomQToolTip 和 QFluentWidgets 的原始源码。采用 [niklashenning/pyqttooltip](https://github.com/niklashenning/pyqttooltip/tree/c73d16404b2621e5f4a2faba8755a9c26c10135c) 的四方向几何实现，直接用于原生 PySide6；它体积小、能围绕目标定位，适合桌宠气泡。卡片绘制和实际轮廓避让按本项目需求实现。

移植保留 MIT 原文，并修正上游侧方垂直居中时误用宽度的问题；补充了斜侧方、脸部避让、任务栏工作区约束、负坐标屏幕和消息间换位。具体来源、固定 commit 及改动见 [第三方说明](../third_party/pyqttooltip/README.md)。研究快照保留在 `artifacts/bubble_refresh/research/`。

## 使用者角度的判断

短反馈应当像角色在身边说话：卡片贴近头部、方向明确、不要盖脸，也不要因为角色轻微呼吸而左右乱跳。长评论应当完整可读，同时限制占屏面积，因此采用自动分页。50% 桌宠的字体也按要求同比缩小，适合短反馈；读长评论时仍可点击关联气泡打开完整对话。

验证报告和实图集中在 [artifacts/bubble_refresh](../artifacts/bubble_refresh/)。离屏测试平台的 emoji 字体回退与 Windows 原生平台不同，离屏预览中的方框不能作为原生 emoji 显示结果；原生截图和测试另行保留。真实多屏热插拔与外部 API 回复不属于本轮验证。
