# R21 目录二次元数据检查

目录列表工具在初次路径检查后还会读取一次目标目录元数据。旧实现只在第二次检查确认“仍是目录”，漏掉了该次已经出现的重解析、离线或云端回调标记。合成路径切换反例中，工具因此读取了外部标记条目的元数据，并返回完整状态；没有读取实际用户目录或文件正文。

现在复用已有标记检查，在第二次元数据已不安全时返回固定的 `reparse_or_offline_path`，不继续列目录。四类标记、正常目录对照及原有相关检查共 24 项通过；原始失败和原源码保留。

随后只澄清模块说明，明确路径检查与打开目录不是原子操作，运行代码 AST 与上述 24 项运行时一致。最终源码另通过三个独立的合成边界：第二次出现符号链接模式、多个标记组合、第二次权限错误，均没有继续枚举，输出没有泄露底层异常详情。

这次补上的是已经观察到危险标记却继续读取的分支，不宣称解决最后一次检查到打开目录之间、或祖先目录同时变化的全部竞态。工具仍只读取元数据，不删除文件、启动程序或开放更多权限，模型调用为 0。
