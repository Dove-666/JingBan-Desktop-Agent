# 旧产物清理记录

2026-11-14，Windows 1.0.2 / Android 1.19.1。

## 结果

独立检查确认清单中的 486,653 个旧文件已全部移除，合计 65.204 GiB。范围仅限项目内旧 artifacts、旧 Windows/Android 安装包及需求分析旧导出；空目录随后清理。未对 Git 历史作重写。

保留全部 MD、当前源码与测试、可编辑美术源文件、开发环境、当前依赖、原发布签名及最新安装包。当前构建依赖集中到 `artifacts/windows-build`，可重复使用的封装验收脚本移入 `tools/qa_release`。用户的设置、聊天、记忆与桌面资料不在删除范围。

新包先完成源码对应、隐私、签名与完整性检查，再核对 SHA256 后开始清理。清理拒绝越出项目和跳转路径，逐文件核对长度与修改时间；发生变化或被占用的文件不会强行删除。初次执行因逐文件目录检查过慢而中断，改用等价的原生属性查询后续跑；路径限制与保留范围未放宽，最终独立核查剩余旧文件为 0。

另有 4 个当前版本原始命名 APK 与简名交付包重复，合计 81,117,124 字节（约 77.36 MiB）。额外删除被自动审批拦截，未提供具体原因，已停止该操作并保留文件。不能把它们算入已释放空间。
