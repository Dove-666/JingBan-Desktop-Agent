# 鲸伴桌宠使用体验审阅 · 2026-10-31

这次按使用者的实际任务审阅现有项目：打开桌宠、阅读和恢复聊天、查找历史、管理记忆、理解主动评论、使用设置。没有修改产品代码、替换素材或改变真实服务配置。测试使用当前 Python/PySide6 应用、已经接入的本地 React/WebEngine 聊天页面、临时 SQLite/Qdrant、内存凭据和模拟模型响应。

目前最值得优先改善的是聊天失败后的恢复、用户能否理解当前状态，以及记忆管理的完整性。会话隔离、上下文预算和感知权限已经有较完整的基础，不需要重建架构。

以下“已复现”来自实际控制器、界面或本地存储实验；“建议”表示尚缺的体验能力。优先级表示建议处理顺序，并不表示已经造成生产数据丢失。

从日常陪伴体验看，还可以做三项小改进：感知状态卡显示剩余冷却、每小时可用次数和上次成功分析时间；旧预览显示“采集于几点、多久以前”；统一“设置 / 控制台 / 调试面板”的入口名称，将素材路径、版本徽标和调试参数放进高级区域。它们能减少“为什么不说话”“这是实时画面吗”“应该到哪里设置”的理解成本。

本轮没有把下列已经完成的行为重复当作问题：本地观察和远程发送分别默认关闭；撤销许可立即生效；托盘暂停可恢复且不额外授予权限；隐藏桌宠会关闭气泡；屏幕评论保存为正式会话消息后可通过气泡进入关联对话；关闭面板保留当前运行期间会话；新会话与旧会话上下文隔离。
