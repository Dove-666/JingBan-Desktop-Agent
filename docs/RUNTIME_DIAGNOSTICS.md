# 启动、退出与异常诊断

R20 在取得当前配置的单实例生命周期锁后启用本地诊断。日志位于配置目录下的 `diagnostics/runtime.jsonl`，轮换文件为 `runtime.1.jsonl`。正常生成的两个文件各不超过 128 KiB，每条记录不超过 1 KiB；不增加轮询、后台心跳、网络请求或新界面。

只记录 UTC 时间、PID、随机运行标识、版本、固定事件与阶段、整数退出码，以及允许的异常类型和内部源码相对位置。异常正文、参数、备注、源码行、绝对路径、环境变量、聊天内容和 API 值不进入日志。未知类型使用固定代称，不序列化任意对象。

| 事件 | 能说明什么 |
| --- | --- |
| `startup` | 本进程已经取得配置的生命周期锁，开始初始化应用。 |
| `quit_signal` | 收到会话的退出信号；不能据此判断谁发起了退出。 |
| `about_to_quit` | Qt 开始退出事件循环。 |
| `event_loop_return` | 事件循环已经返回及其整数返回值。 |
| `exception` | 观察到固定类别的异常，附当前阶段及安全代码位置。 |

这些记录不能代替进程树闭合凭据，不能用于自动重放结果未知的电脑操作。配置尚未建立、单实例锁尚未取得、导入依赖失败、原生崩溃或强制终止可能没有相应结束记录。此前两条旧进程为何消失仍然未知；增加诊断不等于已修复该退出原因。

写入前检查本地目录祖先、重解析点、普通文件和硬链接数量，打开后再核对文件身份。已有超限或归属不确定的文件保留并停止写入，避免截断其它文件。磁盘或权限错误不会阻止启动和退出。关闭时仅解除自己的信号订阅，并只在钩子仍属于自己时恢复原钩子；不改动其它组件后来安装的钩子。

本轮使用临时配置完成 14 项单元及入口替身测试、7 项独立复核、13 项既有真实 Qt/本地 IPC 启动兼容性测试，以及一个真实非可见 Qt 事件循环检查。链接保护的修复前反例、原始替身错误及后续冻结结果分别保留。祖先重解析点的独立反例采用属性模拟，未声称完成真实 junction 的系统验收。没有启动真实用户桌宠或调用模型。
