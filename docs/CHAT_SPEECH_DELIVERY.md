# 聊天回复同步到桌宠气泡 · 2026-10-31

此前普通聊天完成后只向角色发送表情信号，没有把回复正文送到气泡。表情控制又默认使用演示文案，所以聊天窗口里有真实回答，角色旁却只会说“好开心呀”等固定句。

现在普通聊天和重试成功后，从已保存的 assistant 消息取原文及真实消息 ID，经独立回复信号交给桌宠。聊天触发的表情只负责切换表情；完整回答由气泡显示一次，保留段落、空格与换行，长文沿用自动分页。点击气泡会打开对应会话并定位到该条回复。

历史加载、会话概况更新和屏幕评论保存不会触发此回复信号。屏幕评论继续由原感知控制器显示，避免重复。切换会话后，迟到的回答仍保存到原会话，当前桌宠不弹旧回答；清空或删除关联会话时关闭对应气泡。请求失败不生成替代回复，也不会显示固定表情文案。

回调重新检查请求令牌、当前会话与失效状态：上一轮刚结束便立即发送下一轮时，旧回复、旧表情和旧错误不会覆盖新请求的思考状态。没有额外向外部模型发送请求，也没有修改用户 API 或屏幕感知设置。

新增集成回归见 [test_chat_speech_delivery.py](../tests/test_chat_speech_delivery.py)，使用真实应用控制器、临时 SQLite 和 loopback HTTP/SDK；不读取用户凭据、不写入正式聊天记录。回归与正式应用重启证据保存在 `artifacts/chat_speech_delivery/`。

本轮 10 项新增集成测试及 128 项相关聊天、会话、桌宠、气泡和屏幕评论回归通过。它们是定向检查，不是一次新的全仓回归；没有调用用户的外部模型服务。
