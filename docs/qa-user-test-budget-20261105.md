The shared fixture has now been changed to a literal loopback default endpoint and an explicit disabled metadata factory. A guarded reproduction of the old fixture blocked one public DNS request before resolution; this one blocked request is not asserted as the original run's count.

Its parent-Python guard checks DNS, connect/connect_ex, asyncio connection creation and Proactor socket connections, permitting literal loopback only. Therefore the result is scoped test evidence rather than a machine-wide network audit.
