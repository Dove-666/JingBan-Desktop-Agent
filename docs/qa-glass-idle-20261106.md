# R21 聊天玻璃静置检查

这次未发现主聊天玻璃持续绘制的问题，因此没有修改界面源码。实际编译界面的输入区使用静态玻璃；可见、隐藏各观察约 12 秒，两段新增动画帧调度和 Canvas/WebGL 绘制均为 0，页面没有活动的 Web Animations。

测试只使用一个自有聊天窗口和合成记录，没有调用模型、访问系统剪贴板或用户配置。观察包装器只记录现有绘制调用，不创建额外动画循环。六份相关源码与构建文件的散列在前后保持一致，测试窗口已关闭。

父测试进程两段累计 CPU 时间分别为 0.03125 和 0.0625 秒，已知网页渲染进程均为 0.0 秒。这是短时、粗粒度观察，包含测试事件泵；不能据此推断隐藏更耗资源，也未测量 GPU、功耗或完整应用的长期表现。可选折射分支仅检查源码，没有在此次主聊天场景中启用。
