# Agent 可靠性验收

本轮以真实任务的交付结果衡量能力。工具数量、框架名称、模型声称完成和单元测试通过，均不能代替用户目标已经实现的证据。

## 已接入的机制

- 原始任务绑定的目标合同、实际工具观察、当前文件内容与版本检查，再叠加独立语义验收。无关的系统查询不能证明要求的文件已创建。普通问答允许直接回答。
- 文档内容检查直接读取真实 DOCX、XLSX、PPTX 字节、正文及单元格类型；内容通过不代表视觉排版通过。要求 PDF 或排版时仍需相应证据。
- 桌面和手机逐段显示回复。停止、断流保留可见部分并标记中断，不自动重放请求。服务商明确拒绝模型窗口、且尚无任何模型输出时，桌面可尝试一次更小的上下文；系统指令、当前问题和当前图片保持完整。
- `context.get` 只向已授权设备导出会话绑定的摘要、来源与相关记忆。缓存绑定设备、会话、首条消息代次；失效时整体替换。提取式摘要明确只包含部分旧信息，原始档案继续保留。
- `run_code` 是独立进程中的 QuickJS 纯 JSON 计算。没有 Python 对象、宿主回调、模块加载器、文件、环境、网络或终端接口。文件输入、保存与授权仍由现有文件工具负责。它不是操作系统隔离的通用 Python 或终端。
- 已认证手机请求可通过 `agent.queue.v1` 进入宿主 SQLite 串行队列：先保存真实消息并确认接收，再按当前配对身份、会话代次、设置和权限派发。每次首次提交与检查点提交均重新检查授权，取消不重放已执行操作；重启时未知效果仍占执行槽，不能凭进程 ID 消失或模型文字解锁。详见 `HOST_JOB_QUEUE.md`。
- 独立目标验收的安全诊断区分合法的“无法判断”、回执不合法及接口错误，只记录固定原因码；不会保存隐藏推理或原始接口错误，也不会因此自动重试或放宽成功条件。
- `delegate_research` 可将已授权的 UTF-8 文件分配给独立只读子任务，同时运行最多两个。每条引用绑定实际读取和文件版本；主任务仍需复核，子任务的文字不能代替完成或授权凭据。详见 [资料子任务](RESEARCH_RUNTIME_INTEGRATION.md)。
- 本机已配置的 LibreOffice 路径可将生成文档导出为 PDF，再读取文本；页面观察使用授权 PDF 当前版本的不透明引用。只核对某页不能据此宣布整份文档排版正确，也不等同于 Microsoft Office 的显示效果。详见 [渲染接线](LIBREOFFICE_WORKER_INTEGRATION.md)。
- 本机文字草稿按会话保存，两个面板共享版本；清除记录、删除会话及实际归档写入结束后的退出排空分别处理。106 次核心/原生检查、40 次真实 WebEngine 与重绘检查、10 项独立可见恢复检查通过，均使用隔离数据且未调用模型。这些是该批次的测试执行数，不能当作真实任务成功率。详见 [草稿记录](LOCAL_CHAT_DRAFTS.md)。
