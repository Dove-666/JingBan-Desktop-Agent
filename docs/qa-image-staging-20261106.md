# 2026-11-06 图片导入与会话切换

原先图片导入进度和错误是整个聊天窗口的状态。在 A 对话准备图片时切换到 B，B 的纯文字发送会被阻止；A 的导入错误也可能出现在 B。修改前的实际隐藏面板检查重现了这两种问题，未取得旧版可见截图，不能把修复后的截图当成修改前证据。

现在进度、附件和错误按会话显示。A 导入图片时，B 仍可发送文字或移除自己的已有附件；返回 A 后保留 A 的草稿与导入结果，后台失败也只在 A 显示。图片选择器仍等待唯一导入工作结束，避免并发导入；它的可用状态与当前对话的导入进度分开传递，旧宿主缺少新字段时仍兼容原状态。

清空、删除会话会立即废弃该会话的待导入结果和错误。尚未结束的物理导入继续占用导入槽，但不再阻挡文字发送；旧结果到达后只释放槽，不恢复已失效的附件。错误使用固定文本，不显示原始文件路径或异常正文。
