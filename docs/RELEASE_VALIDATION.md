## 本轮修复

- Agent 续办保留原始目标和用户修订，自动验收反馈不冒充用户新要求；未知工具、交替失败及重复无进展的完成请求能停止。有效任务仍不限总步数。
- 停止聊天会取消属于该请求的记忆查询；记忆写入前记录所属模型，取消或超时后不丢失身份保护，空库也能在设置中重置。
- 屏幕分析格式错误会明确失败，不再计为成功；延迟返回的评论重新核对窗口，避免把旧画面评论发到新场景。
- 超过 8,000 字的 Agent 补充指令在发送前提示，失败保留草稿；普通聊天不套用此限制，表情按字符计数。
- 手机阅读旧消息时不被流式回复拉走；草稿改为后台合并保存，补齐未落盘恢复和迟到回执边界；角色目录与实际角色不同步时可重新切换。

详细原因和回归记录：[Agent](qa-agent-reliability-20261114.md)、[记忆与感知](qa-perception-memory-reliability-20261108.md)、[Android](qa-android-reliability-20261114.md)。历史失败和修正后的复跑分开记录，重复执行不累加成独立用例数。

## 隐私与清理

保留全部 MD、当前开发源码、可编辑美术源文件、必要依赖及最新安装包。旧包、重复打包目录和临时生成素材按明确清单清理。当前验收脚本保留在 `tools/qa_release`；构建依赖集中在 `artifacts/windows-build`；当轮原始证据集中在 `artifacts/release-validation` 与 `artifacts/reliability-fixes`。历史版本结果见[上一版记录](qa-release-1.0.1-history.md)。
