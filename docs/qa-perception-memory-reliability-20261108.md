# 记忆与主动感知回归（2026-11-08）

本轮修复桌宠优化记录中的 05–08 项。使用临时配置、合成画面、受控进程边界和本机模拟模型服务；未读取用户聊天或调用用户配置的外部模型。

## 修复

- **停止聊天仍等待旧记忆检索**：检索绑定本次请求的取消标识，停止或退出聊天时只终止所属辅助进程。排队和进程启动中的取消同样生效；延迟初始化不阻塞界面，也不会关闭其他会话共用的记忆服务。
- **错误输出被记为分析成功**：解析结果明确区分无效结构和合法的安静结果。错误格式不会清除错误、记录分析成功时间或接受画面基线；原有请求间隔继续生效。
- **评论保存后情境已经变化**：保存回调显示气泡前再次验证原窗口或设备。过期评论保留在关联会话，不弹出气泡、不消耗主动发言额度。手动评论旧预览的既有规则保留。
- **部分向量写入后丢失模型标识**：向辅助进程提交写入前原子保存模型身份。超时、取消或输出解析失败都不会解除保护。旧无标识库只有经本地检查确认所有集合为空后才能绑定新模型；非空库保留数据并阻止混用，仍可通过本地管理查看和清理。

已开始的记忆写入即使最终返回空结果，也可能保留模型标识；更换向量模型前需要先清空该库。程序不会自动猜测旧向量属于哪个模型或删除旧数据。

相机回归最初有两项失败：测试隐含假设屏幕感知默认关闭，而产品先前已按用户要求默认开启。已将独立权限测试的起始屏幕状态显式设为关闭，再验证相机开关不改变该状态；没有修改产品默认设置。

这不是实体手机、真实摄像头或云模型质量测试，也不代表所有 Agent 任务都已通过。

## 2026-11-14 收尾复核

补齐了空库的恢复入口：首次写入即使没有生成可见记录，也可能已经绑定模型。设置页此时显示“重置记忆库”，确认后解除空库绑定；其他用户的数据仍受保护。实际 `MemoryController` 与 Qt 面板回归验证了点击确认、清除标识、按钮消失以及重新选择模型的完整流程。新建空库不会多显示此按钮。

旧库检查、等待存储锁与正式请求共用一次超时预算。另补了身份标识写入期间取消、超时两项回归：均未向辅助进程发送变更请求，已经写下的身份保护仍然保留。

本次验证均使用临时目录、Qt 离屏界面、合成数据及本机模拟服务，没有调用用户的外部模型或操作用户记忆库。

| 批次 | 结果 |

| 记忆取消、设置页、就绪状态、解析与评论定向验证 | 116 项通过，56.581 秒 |
| 记忆、感知、相机扩大回归 | 412 个不同用例，551.963 秒；初次有 3 个用例失败，对应 3 条子用例失败记录和 2 条异常记录 |
| 更正与分页夹具修正后的复跑 | 该模块全部 6 项通过，141.123 秒；扩大批次中其余 406 项已通过 |

扩大回归的失败均来自旧更正测试直接向 Qdrant 填入向量，却没有记录所属模型，新保护因而在真正更正前就拒绝继续。现由测试夹具明确写入它自己使用的模型标识，再验证更正、过期状态、来源校验及用户隔离；没有放宽产品对未知旧库的保护。上述 412 项为去重后的覆盖范围，初次失败记录保留，不把多次执行次数相加当成新增用例。

另独立复核了核心任务恢复：重试失败恢复及真实 SDK 的自动检查反馈／重启，共 18 项通过（11.765 秒）。该数字与核心模块自己的验证存在重叠，不能重复计入项目总数。没有因这些检查修改核心源码。
