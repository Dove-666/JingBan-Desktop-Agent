以下是上一版的原记录，仅代表当时版本。2026-11-14 清理旧包与临时报告，历史结果没有改写为新版通过。

# 验证记录

Windows 1.0.1；Android 1.19.0。

## 功能与封装

- 新配置默认浅色、角色大小 100%，电脑 Agent、任务工具、电脑操作默认开启；已保存的选择保留。
- 新模型选择已识别支持的最高思考档位，保留手动选择；未知模型不猜测接口参数。
- 手机设置包含角色卡入口，连接后同步角色设定；离线沿用最后同步的当前角色。
- 安装器删除额外信息页，界面仅在设置底部展示版本。
- 电脑端重新冻结当前源码；主程序、外置工作进程、网页和所选素材逐项对照。签名与版本校验保留安卓原发布身份。

## 检查范围

- 266 项桌面相关回归，0 失败、0 错误、0 跳过，源码指纹稳定。
- 299 项 Android 单元检查、29 项原生模拟器界面检查，草稿字节保持。
- Windows 独立目录验证启动、聊天、草稿恢复、两种本地棋局、网页桥，以及安装和卸载后的用户数据保留。
- 完整包体清单、ZIP 成员 CRC、安装文件 SHA256、PE 版本与安卓签名、ABI 和 16 KiB 对齐校验。

模型请求使用本机确定性测试服务或无网络界面夹具，没有调用真实付费模型。这些结果不代表任意 Agent 任务、另一台电脑、实体手机、蜂窝网络或公共中继均已通过。

## 隐私

- 源码候选及最终 Git 暂存对象独立检查。个人设置、凭据、聊天数据库、配对数据、个人参考照片、缓存和生成的安装包不进入源码仓库。
- 开发机路径改为可移植路径；新提交使用 GitHub 隐私邮箱。
- 电脑包同时检查原始文件、压缩成员与压缩 Python 字符串；安卓包检查 DEX、原生库与压缩成员。
- 本地回归所需的自签名 TLS 证书和 SQLite 迁移夹具保留；它们使用受控合成数据，不是用户身份或聊天数据库。
- 安装包通过 GitHub Releases 分发，下载后可用同页 SHA256SUMS.txt 校验。

生成项目代码的执行限制保持原状；清理路径和封装不会解除既有的隔离限制。
