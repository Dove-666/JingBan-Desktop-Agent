# R21 已发送小图的查看标签

图片粘贴、拖入功能验收后的截图中，发现已发送小图片的查看标签被截断。实际四组对照确认：24×16 图片成功加载后，按钮也只有 24 px 宽，而完整标签需要 92 px；640×430 的正常图片在宽、窄窗口中均正常，不是普通照片的懒加载收缩问题。

修复只调整三个图片样式选择器：预留框和按钮至少 112 px 宽，仍限制在可用宽度内；图片按原始尺寸居中，并保留最大宽高。小图不会放大失真，正常图片继续按比例缩小。附件组件、懒加载、缓存、图片读取和点击打开原生预览的逻辑均未改。

相同四组对照在 1000 px/16 px 字号及 420 px/22 px 字号复测通过：标签完整、无横向溢出、小图保留原始像素、正常图片比例正确，原生预览能打开并关闭。另运行 15 项图片界面和 5 项阅读位置检查，20 项通过；测试窗口已关闭，相关源码在运行期间保持不变，真实模型和系统剪贴板调用为 0。
