# 鲸鱼娘日常使用

安卓 1.9.0 顶部显示当前对话主题，右侧电脑状态图标可打开连接详情；模型配置详情默认收起。电脑离线时选择「电脑 Agent」会打开连接面板，保留草稿与模式。手机与桌面执行过程完成后自动折叠，可点击展开步骤和详情；步骤的 `+00:12` 表示从任务开始后的时间。

桌面聊天与内嵌设置窗口采用 R24 圆角与细描边，外轮廓使用透明背景上的抗锯齿绘制。窗口内容与按钮内缩 8 像素；最大化或全屏时恢复直角和零留白，还原后恢复圆角。

## 从聊天开始

点击桌宠打开聊天，也可以双击 Windows 通知区的鲸鱼娘图标。
关闭聊天窗口只收起面板；当前对话、草稿和桌宠仍在本次运行中保留。
新建对话会开始独立上下文，旧对话继续保存在历史中。
聊天继续使用白色主题；历史侧栏、消息、代码块、工具菜单和重命名窗口保持同一套浅色样式。

- Enter 发送，Shift+Enter 换行。中文输入法选词时不会误发送。
- Ctrl+N 新建对话，Ctrl+F 展开历史并搜索。Esc 收起辅助内容；小窗口历史抽屉关闭后，焦点回到打开它的按钮。
- 小窗口默认收起历史，点击左上角历史按钮展开。抽屉打开时，Tab 与 Shift+Tab 在抽屉内移动，不会跳到遮罩后的输入框。
- 历史列表只显示单行标题；长标题省略显示，悬停可查看完整标题。
- 右上角“对话工具”中可进入长期记忆、聊天服务设置和上下文预算。
- 来自屏幕感知的评论有“来自屏幕感知”标识；展开后可查看关联摘要、应用和采集时间。
- 阅读前面的消息时，新消息不会强制把滚动位置拉到底部。
- 草稿按会话分别保留，切到另一会话再返回，不会把未发送文字放错对话。
- 回复中的 HTTP / HTTPS 链接可交给本机默认浏览器打开，旁边的复制按钮只复制链接地址；复制成功后显示勾选反馈。含用户名或密码的地址、本地文件与其他协议不会成为可操作外链。
- “对话工具 → 阅读字号”可单独调整聊天正文与输入框，范围 12～22，默认 16，设置自动保存；窄窗口不会自动缩小文字。它与角色大小和桌宠气泡字号相互独立。
- 代码块右上角的“复制代码”只复制该段代码，保留缩进，不带前后说明文字。
- 新版聊天的“对话工具 → 查找当前对话”或 Ctrl+Shift+F 可查找本会话全部已保存消息。在查找框中按 Enter 跳到下一条、Shift+Enter 跳到上一条，也可用 F3 / Shift+F3 导航；Esc 关闭查找。查找框旁显示匹配消息数，结果循环导航。查找不发送请求，不会改动聊天内容或草稿；聊天输入框的 Enter 仍然发送消息。Ctrl+F 仍用于搜索历史会话。
- 从历史正文搜索结果打开对话时，会定位到一条命中消息；只匹配标题时正常打开对话。重命名弹窗内的 Ctrl+N / Ctrl+F 不会操作背后的会话，中文输入法选词时 Enter 不会提交名称。Tab / Shift+Tab 在弹窗内移动，关闭或保存后焦点回到聊天输入框，可以继续打字。

首次使用可从聊天“工具 → 聊天服务设置”或空会话提示进入“API 设置”，保存服务商地址、模型与密钥，并测试连接。
未经配置的服务不会被显示为连接成功；失败不会影响拖动和使用桌宠。

发送后，底部会依次显示实际进行的阶段：保存消息、检索相关记忆、生成回复、保存回复。
没有开启记忆时跳过检索阶段；界面不是按时间假装推进。
处理中切换会话会提示请求属于另一会话，回到原会话可继续看到实际阶段。
连接测试使用独立状态，完成或失败后恢复可操作状态。

回复失败、主动停止或上次运行中断后，原用户消息下会显示“回复失败”“已停止生成”或“上次请求未完成”，并提供“重试回复”。
重试针对这条原消息及其原会话，不会把其他会话的最后一句重新发送，也不会新增一条重复的用户消息。
切换会话、关闭窗口或重启后，重新打开原会话仍能查看已保存的请求状态；有待恢复的消息可以就地重试。

处理中可点击“停止生成”停止等待本次回复；切到另一会话时，停止按钮仍对应正在执行的请求。
服务端可能已经收到请求，停止无法撤回已经传输的数据。停止后可继续聊天，也可在原消息下重试。
如果旧记忆检索仍在结束，原消息会显示原因并暂时禁用重试；收尾结束后按钮自动可用。停止不会删除历史消息；未完成回合不会作为完整对话进入新生成的概况或后续模型上下文。
设置缺失时，错误提示提供“打开 API 设置”；历史读取失败时提供“重新读取”；可恢复的回复错误提供“重试回复”。

聊天网页加载失败时，可选择“重新加载聊天界面”或“使用兼容聊天”。
兼容聊天可以继续发送和浏览历史；点击“返回新版聊天”可重新尝试白色聊天界面，同一会话的草稿在两种界面之间保留。

## 选中网页文字，问问鲸鱼娘

Edge / Chrome 可安装项目内的轻量扩展：在普通网页中选中文字，右键选择带鲸鱼图标的“问问鲸鱼娘”，即可打开独立提问框。它会展示本次选区、页面来源和可选的正文预览；输入问题后点击“发送提问”，也可以先选择“解释一下”“总结重点”或“翻译成中文”再发送。

首次安装在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_browser_ask.ps1 -Apply
```

然后打开 `edge://extensions/` 或 `chrome://extensions/`，启用开发人员模式，选择“加载解压缩的扩展”，选中项目的 `browser-extension\whale-ask` 文件夹。开发人员模式需保持开启，当前 Edge 关闭它会禁用本地解压缩扩展。脚本仅登记当前用户的本地连接桥，不会代替浏览器加载扩展，不需要管理员权限。桌宠仍运行旧版本时，先从角色右键退出再重新启动。

- 打开提问框时不调用模型，确认发送后才使用原有聊天 API；没有配置 API 时保留提问内容并显示原因。
- 提问框优先展示选中文字；长标题与网址单行省略，悬停可查看完整来源。网址的编码会解码后显示，引用资料中的原始地址保持不变。小窗口可滚动参考资料，输入框和发送按钮保留在底部。
- 问题发送到当时的活动会话，不创建另一套聊天记录。消息下的“引用选区”可展开查看来源，重试及近期追问可以继续引用这次页面内容；历史侧栏仍只显示标题。
- 只在点击菜单时读取本页可见文字，不截图、不持续观察网页；默认最多附带 8000 字符选区和 16000 字符页面正文，实际发送继续受统一 Token 预算限制。正文不是整页无限发送，来源片段会在本地会话中保存。
- 输入框、密码框与可编辑区域暂不支持。受保护页面、部分跨域嵌入内容无法提取正文时，保留选区并明确提示；本功能当前理解页面文字，不识别视频或图片中的内容。
- 页面正文作为引用资料处理，不能执行其中的指令；不会据此自动提炼用户长期偏好。关闭提问框不发送、不保存这次选区。已有提问正在生成时，会提示等待并保留新问题。
- 本地连接失败时，扩展会显示具体错误和恢复方法；已启动的当前版本桌宠会直接接收，未启动时尝试启动一次。

卸载本地连接桥：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\uninstall_browser_ask.ps1 -Apply
```

浏览器内可单独移除“问问鲸鱼娘”扩展。完整安装参数见 [扩展说明](../browser-extension/whale-ask/README.md)。

## 导出一段完整对话

1. 在历史中打开需要的会话，确认上方标题。
2. 点击“工具 → 导出当前对话”，选择 Markdown 或 JSON 和保存位置。
3. 等待“已导出”提示。导出期间可以浏览历史；切换会话不会改变已经选定的导出对象。

导出读取这段会话的完整已保存消息、概况和关联屏幕文字情境，不受聊天上下文的 16 条近期消息限制。
它不会把 API 配置、系统凭据、截图或内部 JSON metadata 加入文件；消息中的内联图片数据会被省略。
Markdown 对动态 HTML 和图片语法做安全处理，JSON 适合查看结构化字段和保留文本数据。
新空对话没有已保存消息时无法导出。取消文件选择不会生成文件；正常写入失败会保留已有目标并清理临时文件。
若程序补全扩展名后遇到另一个已有目标，会再次要求确认覆盖。

导出文件由你自行保存和分享，其中仍可能包含对话中主动说过的私人文字。
本轮不提供自动导出或自动上传，也不把导出文件作为备份全部配置的方式。

## 在通知区控制桌宠

托盘菜单提供聊天、控制台、长期记忆、显示/暂时隐藏桌宠、暂停屏幕感知和退出。
Windows 可能将图标收入通知区的折叠列表。
没有系统托盘的环境不会允许隐藏角色，避免失去打开入口。

“暂停屏幕感知（本次运行）”立即停止后续截图和分析，并清除当前预览。
它不改写保存的授权；恢复时仍遵守当前的本地观察与远程分析开关。
取消勾选观察或远程分析则会立即撤销对应权限，再尝试保存。
如果保存失败，本次运行仍保持关闭，界面会提示下次启动前检查。
已发出的网络请求无法撤回已传输的数据；取消会阻止后续显示和动作。

聊天顶部会显示当前屏幕感知模式、主动发言冷却和本小时剩余评论次数，可直接“暂停屏幕感知”或“恢复屏幕感知”；点击模式状态可进入感知设置。
屏幕感知与摄像头分别显示状态、分别暂停。“暂停全部观察”只暂停本次运行；恢复时分别选择需要的屏幕或摄像头，不会重开原先关闭的权限。观察状态不等于已经成功调用模型。
识别失败的原因会保留到实际识别成功，并记录在带时间的事件列表；检查设置后可点击“重试识别”。关闭权限时若本地保存失败，会明确提示本次已关闭及下次启动仍需检查的风险，不会用新预览覆盖警告。
感知页还显示下次观察倒计时、分析间隔剩余时间和上次成功分析距今多久；暂停后会明确显示观察计时已经停止。
预览注明采集时间与距今秒数，旧预览会有提醒。返回 AURA 面板后显示的是上次安全预览，不是当前面板的实时画面。
需要更新预览时，使用“3 秒后本地观察”，随后切到目标应用等待采集；本地观察不会自动调用评论 API。

## 阅读桌宠气泡

打开“控制台 → 角色控制 → 评论气泡阅读”，可将气泡字号调整为 **12～22 pt**；默认 14 pt，调整后自动保存，“恢复默认字号”可还原。
这个字号独立于角色的 50%～200% 缩放，放大或缩小角色不会连带改变阅读字号。

有关联对话的评论气泡支持悬停暂停：鼠标停在气泡上时，自动翻页与自动消失计时都会暂停，移开后继续。
长内容可使用页脚的上一页、下一页区域，也可向上滚轮回到上一页、向下滚轮翻到下一页。
点击气泡正文会打开关联会话并定位对应消息；普通短暂提示仍保持原来的鼠标穿透行为。

## 自动记忆

打开「设置 → 长期记忆」，开启「自动记忆」即可。程序会为新用户准备本地中文检索模型并复用聊天服务，不需要填写模型、维度或独立密钥。首次准备需要下载模型，请保持网络连接；失败后可以点击「重新准备」。仅打开页面不会下载模型。

如果从源码安装，先安装一次可选运行依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-memory-local.txt
```

准备好后，在聊天中说「请记住，我希望回复简洁一些」。有价值的明确偏好会在后台提炼，保存成功后列表自动刷新。新对话会按需检索相关记忆。提炼仍使用聊天服务并产生 API 用量，本地检索不等于整套记忆完全离线。

关闭「自动记忆」会停止新增并保存开关状态，已有内容仍可使用。若开关保存失败，页面会明确说明；普通聊天和已保存的对话不受影响。

## 管理和纠正记忆

在同一页面搜索已保存的内容；记录较多时使用翻页。列表只显示事实，点击一条后可查看来源与时间、修改内容、查看更正历史或删除。来源会话存在时，可以返回原对话。没有记录时只显示简短空状态。

修改失败保留输入，避免重复填写；更正保留原 ID 和历史，编辑失效记录不会重新启用。删除及清空需要确认，并会真正删除对应数据。删除对话与删除长期记忆是独立操作。

已有记忆和自定义服务会保留，程序不会为了改用本地模型而清空旧库。查看、搜索、删除和清空走本地管理路径；编辑可能需要该记忆库原有的检索模型可用。仅删除当前用户可归属的数据，其他用户或无法可靠归属的旧数据不会被猜测删除。

## 窗口与设置

桌宠位置与聊天、控制台、记忆窗口的位置会分别记住。
桌宠大小仍使用原有 50%～200% 控制，不用保存的窗口尺寸覆盖缩放设置。
已移除显示器上的窗口会移回当前工作区；窗口不会覆盖任务栏。
最小化后重新打开会恢复窗口。

退出请使用桌宠右键或托盘的“退出桌宠”。原图、角色建模与动画未在本轮修改。

## 启动故障的只读检查

```powershell
.\.venv\Scripts\python.exe -m desktop_pet.diagnostics
.\.venv\Scripts\python.exe -m desktop_pet.diagnostics --json
```

诊断显示 Python / Qt / 依赖版本、64 位状态和 PNG 格式、尺寸、Alpha 与可读性。
即使缺少 PySide6，也会给出缺依赖结论；可选 Mem0 缺失不会误报普通桌宠不能启动。
它不启动桌宠、不读配置或凭据、不读聊天与屏幕、不联网、不初始化数据库，也不加载向量模型。
报告默认不包含用户名、用户路径或服务地址，适合手动分享排查；检查通过不代表 API 已连接或模型已经可用。
完整字段和退出码见 [本地只读诊断](DIAGNOSTICS.md)。
