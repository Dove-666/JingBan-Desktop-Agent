# 开始使用鲸伴

## 安装

在 [Releases](https://github.com/Dove-666/JingBan-Desktop-Agent/releases) 下载已发布的安装文件。源码中的版本号不代表对应附件已经发布。

- **Windows 安装版：** 运行 `鲸伴安装.exe`，完成后从桌面或开始菜单打开。
- **Windows 免安装版：** 完整解压 `鲸伴.zip`，运行其中的 `鲸伴.exe`。不要只取出一个 exe，旁边的 `_internal` 是必需组件。
- **Android：** 通常安装 `鲸伴.apk`；若手机架构不匹配，再选择通用或对应架构附件。同签名版本可覆盖升级，建议保留现有应用数据。

Windows 包面向 x64 系统，推荐 Windows 11。安装包尚未做发行者代码签名。版本对应的实际测试范围见[验证记录](RELEASE_VALIDATION.md)。

## 配置一次 API

点击桌宠打开聊天，进入 **设置 → 模型与 API**，填写服务商地址、模型名称与自己的 API Key，保存并测试连接。聊天、电脑 Agent 和画面分析共用这套配置，模型是否支持相应能力取决于服务商。

| 用途 | 模型需要的能力 |
| --- | --- |
| 文字聊天 | 兼容的文本对话接口 |
| 图片对话、屏幕感知 | 图片输入 |
| 电脑 Agent | 工具调用；视觉电脑操作同时需要图片输入 |

程序会根据接口和模型显示适用的思考设置。未知模型不会强行发送不确定的思考参数。模型列表能返回名称，不代表列表中的每个模型都能识图或使用工具。

API 使用费用由所选服务商收取。安装包不提供共享密钥。桌面凭据使用系统凭据存储；手机同步到的密钥使用 Android Keystore 加密保存。

## 聊天和桌宠

点击角色或双击托盘图标打开聊天；拖动角色可改变位置。关闭聊天窗口只收起窗口，完整退出请使用桌宠右键或托盘的退出入口。

聊天支持文字、图片、历史会话和草稿。电脑 Agent 的执行过程位于对应回复中，结束后收起，点击可展开。生成文件的卡片跟随生成它的回复，点击保存时自行选择位置。

在 **设置 → 角色 → 角色卡** 导入 PNG 或 JSON，可预览、应用并保存到角色库。角色设定影响说话风格；任务权限仍由电脑 Agent 的权限选项管理。

## 屏幕感知

新配置默认开启屏幕观察和画面发送。设置 API 后，符合变化、时间间隔和互动条件的截图可能发送到所选模型服务商；不需要时可在设置或右键菜单关闭屏幕感知。

系统先做本地变化筛选，再请求多模态分析，最后结合用户状态、发言冷却和小时配额决定是否回应。它不会持续评论每一帧画面，也不能保证对所有画面理解准确。摄像头是独立的可选功能。

## 电脑 Agent

在聊天中选择 **电脑 Agent**，描述目标后发送。任务直接进入 DeepSeek Harness 工具循环，无需使用特定提示词。

输入框旁的权限菜单提供三个选项：

- **请求批准：** 联网、修改工作区外文件及执行命令前询问。
- **帮我批准：** 使用 DSH Auto Review 审查工具操作，有风险时询问；审查会增加 API 请求，也可能判断错误。
- **完全访问权限：** 自动执行已启用工具；缺少任务信息时仍会提问。

任务使用当前 Windows 用户权限，默认工作目录不构成系统级隔离。需要时使用停止按钮；已经完成的文件修改或电脑动作不会因此自动撤销。详细行为见[Agent 说明](ON_DEMAND_AGENT.md)。

## 连接手机

1. 电脑运行鲸伴，在远程连接设置中启用连接并生成配对信息。
2. 手机打开设置中的电脑连接入口，粘贴完整配对信息并确认。配对信息短时有效，不要分享给其他人。
3. 连接后同步对话和角色。手机也可保留自己填写的 API 配置。

手机的 **手机聊天** 可以直接调用 API，电脑离线时仍可使用；**电脑 Agent** 将任务发送给电脑，需要电脑正在运行且网络可达。普通文件通过电脑 Agent 上传和处理，当前单文件上限为 32 MiB。

配对后的通信优先直连，不可直连时尝试公共中继，不要求自建服务器；实际可达性仍受网络和系统后台限制影响。更多安装与同步细节见[Android 说明](../android/README.md)。

## 从源码准备可选组件

先完成[首页的源码启动步骤](../README.md#从源码运行)。以下命令均在仓库根目录执行。

| 功能 | 准备方法 |
| --- | --- |
| 手机连接 | `.\.venv\Scripts\python.exe -m pip install -r requirements-remote.txt` |
| 象棋 | `.\.venv\Scripts\python.exe tools/setup_pikafish.py` |
| 五子棋 | `.\.venv\Scripts\python.exe tools/setup_rapfi.py` |
| 长期记忆 | 按需安装 `requirements-memory.txt`；本地向量模型另需 `requirements-memory-local.txt`，再在设置启用。 |
| 电脑 Agent | 先构建 Windows CUA，再安装锁定的 DSH 依赖；按[当前构建输入与流程](WINDOWS_RELEASE.md#当前构建输入与流程)操作。构建需要 .NET 10 SDK、PowerShell 7 及兼容 Node。 |

源码中的前端由 `npm --prefix frontend/chat-ui run build` 生成到 `desktop_pet/ui/web_chat`。修改前端后需要重新构建；Python 代码更新后需要从托盘退出旧程序再启动，关闭聊天窗口不会加载新代码。

## 常见情况

**桌宠能出现，但不能聊天。** 先检查 API 配置和连接测试。桌宠动画与模型服务是独立功能。

**能聊天，但 Agent 或看图失败。** 确认模型具备工具调用或图片能力，再检查电脑 Agent 的权限开关及组件安装。单纯提高思考档位不会给模型增加这些能力。

**手机连接失败。** 确认电脑运行、远程连接已开启、配对信息完整且未过期。电脑的 `localhost` API 地址不能直接供手机访问。

**升级后仍像旧版本。** 先保存草稿，从托盘完整退出，再运行新安装位置的程序；源码启动和安装版可能是两个不同位置。

**准备反馈问题。** 提供系统版本、设置中显示的版本号、复现步骤和去除隐私后的截图。不要提交 API Key、配对链接、个人聊天数据库或完整个人配置。
