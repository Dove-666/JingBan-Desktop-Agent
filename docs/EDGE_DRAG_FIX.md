# 桌宠拖动边界修复

透明角色素材有大块画布留白，原来拖动时限制整个窗口，导致角色到屏幕边缘前就被挡住。现改为缓存真实 Alpha 边界，按可见角色的稳定活动范围限制位置；透明部分可以移出屏幕，角色仍处于工作区内，底部避让任务栏。呼吸、上浮和跳跃保留少量安全余量，动画不会每帧移动窗口。

静态素材按非零 Alpha 测量，序列帧使用整段联合边界，不逐帧裁切或改变缩放。换素材、播放或停止动画、调整尺寸、显示器变化时重算边界；拖动和绘制继续使用同一个角色变换。保存位置与隐藏后重开也复用可见范围，避免重新打开后被透明窗口边界推回去。普通聊天和调试窗口仍按整个窗口限制。

## 修改文件

- `desktop_pet/placement.py`：可见范围定位、负坐标和最近显示器选择。
- `desktop_pet/pet_window.py`：缓存 Alpha/动画联合边界，统一拖动、缩放和素材切换的边界规则。
- `desktop_pet/ui/window_state.py`、`desktop_pet/application_controller.py`：桌宠位置保存与恢复使用可见范围。
- `tests/test_pet_edge_drag.py`：新增 8 项边缘回归；`tests/test_window_state.py` 增加 3 项位置恢复回归。
- `tests/test_pet.py`、`tests/windows_smoke.py`、`tests/experience_smoke.py`：校验角色可见范围，普通工具窗口的整窗约束保留。

## 实际验证

11 个相关测试模块共 **138 项通过，13.798 秒**。覆盖 50%/100%/200% 大小的四角拖动、负坐标屏幕、透明孔洞、拖动不误触点击、稳定动画边界、序列帧不逐帧读取或重新布局、位置持久化、气泡、窗口和角色控制。`compileall` 语法检查通过。

Windows 原生测试通过，命令为 `.venv\Scripts\python.exe tests\windows_smoke.py --bubble-only`，使用独立测试进程和真实鼠标注入，并恢复原鼠标位置。150% DPI 下，左右上下的安全范围距工作区边界分别为 0.482、0.482、0.019672、0.922 个逻辑像素。透明留白与孔洞的鼠标穿透、键盘焦点、点击、气泡和任务栏避让也通过。首次尝试因 Windows 拒绝前台激活而未完成，未计为通过；原始记录保留，最终成功报告为 `artifacts/edge_drag_fix/windows_smoke.json`。

修复后的两段正式动画各 62 帧，真实素材播放检查通过，涵盖六档缩放、拖动暂停/恢复、停止及结束状态，原图与动画文件哈希不变。加载缓存约 0.886/0.883 秒；最大缩放阶段 GUI 心跳间隔 96.72ms。报告为 `artifacts/edge_drag_fix/real_playback/result.json`。其 PowerShell 日志包装把预期的 offscreen 工作区诊断视为 stderr 并返回 1，测试自身的结构化结果为 `passed`，两段均无断言失败。

本轮未重复运行全仓测试，没有重新验收实际多显示器热插拔；负坐标和显示器恢复使用模拟工作区回归。真实应用启动另由主流程核对，原生物理拖动测试使用独立桌宠窗口。
