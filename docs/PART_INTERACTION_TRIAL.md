# 正常立绘耳尾点击试作 · 2026-10-31

本次只给常驻的正常立绘增加局部互动。点击左、右蓝色鳍耳时，对应耳朵轻摆并回弹；点击右侧露出的尾巴时，尾巴摆动后复位。耳朵约 0.65 秒，尾巴约 0.9 秒，不替换整个人物姿势。

耳尾点击不会打开聊天窗口或切换开心表情。点击身体仍沿用原有功能；从耳朵、尾巴开始拖动也按拖动处理，拖动时冻结当前局部姿态，松手后继续。眼睛跟随、聊天气泡和序列帧播放继续使用原来的时钟。

右键角色可切换“耳尾点击互动”，本次开关仅在当前运行期间有效。其他立绘和序列动画不使用这套分层；素材缺失或校验不符时自动回到原来的静态绘制，不影响桌宠启动。

美术在 Photoshop 中拆出三个透明部件，放在身体与前景头发之后。保留前景遮挡、补足隐藏根部，按原画的透明像素定位。运行时缓存部件、身体底图和与眼睛底图的融合结果，帧更新只计算角度并绘制，没有每帧读文件或新增计时器。

首摆达到素材声明角度，再以阻尼收敛到零；连续点击重新开始对应部位的动作，不累加角度。点击命中按当前旋转的部件 Alpha 反算，透明孔洞与被头发遮住的根部不算部件点击区域。角色可见范围与屏幕边缘约束也包含摆动区域。

运行资产在 `assets/character/interactions/neutral/`，Photoshop 工程、原生 PSD 和美术预览在 `美术资产/鲸鱼娘_耳尾点击试作/`；交互测试、动图与验证记录集中在 `artifacts/part_interaction_trial/`。本次没有扩展到其他六种表情。

12 项局部互动专项与安装素材后的 58 项相关回归通过。真实素材另外逐帧核对 360 个源画布状态及 18 个窗口点击场景：零角度和结束姿态精确还原，未点击部位与脸部保持不变，原 190 份素材哈希未变。动图已完整解码检查，为 1.6 秒、28 个合并帧；它是放大审核预览，实际显示大小遵循桌宠缩放设置。这些是定向验证，不是新的全仓回归。

Windows 物理点击探测因检测到前台窗口发生变化而拒绝发送输入，实际发送点击为 0；已关闭测试自有窗口并恢复鼠标位置。该项如实记为未通过，没有反复重试，也未操作正式桌宠或强制切换前台。上述点击功能证据来自真实 Qt 控件的合成鼠标事件，不能等同于本轮物理鼠标验证通过。
